# Security policy

Report a vulnerability privately through [GitHub security advisories](https://github.com/mcello23/cypress-neo-reporter/security/advisories/new). Please do not open a public issue for it.

From 2.0.0 on, releases are published from GitHub Actions with npm trusted publishing, so each version carries a provenance attestation that links it to the commit and workflow that built it. Check it with `npm audit signatures`.
